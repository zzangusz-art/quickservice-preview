# 실제 배송 사례

11월 14일 이후 블로그는 여기 있는 실제 사례를 먼저 글로 만듭니다(월·수·금 09:23). 사례가 없는 주에는 일반 주제로 월·금 2편만 나갑니다.

## 추가 방법

`_template.json`을 복사해 `날짜-구간.json`(예: `2026-11-12-seongsu-pangyo.json`)으로 저장하고 내용을 채웁니다.

| 항목 | 내용 |
|---|---|
| date | 배송일 |
| from / to | 출발·도착 **동 이름까지만** |
| item | 물건과 수량 |
| vehicle | 오토바이, 다마스, 라보, 1톤 등 |
| situation | 어떤 상황이었는지 |
| handling | 어떻게 배차·처리했는지 |
| result | 결과(도착 시각 등) |
| fare | 실제 요금(공개해도 될 때만, 없으면 지움) |
| category | 분류(없으면 「보내는 방법」) |
| consent | 공개 동의를 받았으면 `true`. `true`가 아니면 글을 쓰지 않습니다 |
| status | `todo`로 둡니다. 글이 되면 자동으로 `done`이 됩니다 |

## 지켜야 할 것

- 이 저장소는 공개 저장소입니다. 고객 이름·상호·전화번호·번지·이메일은 적지 않습니다(전화번호·이메일·번지가 보이면 글을 쓰지 않습니다).
- 있었던 일만 적습니다. 글은 여기 적힌 사실만 쓰고 새로 지어내지 않습니다.
